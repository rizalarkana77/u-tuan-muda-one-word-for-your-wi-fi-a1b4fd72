## The word

> Bandwidthit

Bandwidth + bandit. Every home Wi-Fi feels like it steals your
bandwidth the moment you need it most — the video call freezes, the
download stalls, the bars stay full while nothing loads — and the pun
names the thief in a single word. It reads instantly as a network
name, which is what the winning word becomes.

## Why this word wins

Against the judge's brief, in its own order:

1. **It fits the subject.** It is a word about Wi-Fi itself: bandwidth,
   the one thing a network is for, turned into the culprit.
2. **It is funny.** A bandit hiding in the router, pocketing your
   megabits — the joke lands on the first read, with no explanation.
3. **It is true.** Everyone has lived it: full bars, nothing loads,
   and the bandwidth has plainly gone missing.
4. **It is a fresh angle.** The field is full of ghosts, gaslighting and
   buffering; nobody named the thief. A coined pun word stands out in a
   head-to-head against a plain adjective.
5. **It reads instantly.** One word, one picture: the network that robs
   you. As a network name it is the joke every guest sees.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# writes out/entry.txt, exactly: Bandwidthit
cat out/entry.txt  # verify: one word, no trailing newline
```

## How it runs

1. `main.ts` (Node 22, standard library only) holds the word as one
   constant and writes it, byte for byte, to `$MAKEFUN_OUTPUT_DIR/entry.txt`
   (default `/output/entry.txt`).
2. No network, no randomness, no clock: both runs write identical bytes.
